## 5. 앱 전달·보관 자료

앱은 대표 요청 시 **대표 본인과 본인 지점·모든 하위 지점 관리자/지점이 함께 정리됨**을 안내한다. 일반관리자는 본인만 대상이다. 성공 후 access/refresh·채팅 인증 정보를 폐기하고 로그인 화면으로 이동한다. 응답 유실 뒤 401만으로 탈퇴 성공을 확정하거나 자동 재삭제하지 않는다. 상세 요청·응답·오류는 [전달서](admin-account-deletion-handoff-2026-11-05.md)를 따른다.

격리 소스·관련/전체 테스트 XML·요약, 재시작 전후 설정/작업 지문과 실제 HTTP 결과는 접근 제한된 `build/test-runtime/admin-account-deletion-2026-11-05/`에 보존했다. 결과 문서에 비밀번호·토큰·비밀키·개인정보를 기록하지 않았다. 실제 관리자/지점 복구나 삭제 작업은 이번 검증에 포함하지 않았다.
