## 5. 사용자 지정 branch2 테스트 지점 — 실제 읽기 전용 결과

지정된 테스트 관리자에 연결된 직접 지점 **NR_TEST_20260921-ORG01-SP01**을 DB에서 유일하게 확인했다. 별도 하위 지점은 없다. 작업 전과 배포 후 다시 조회해 같은 결과임을 확인했다.

| --- | --- |
| 미완료 렌트 | **0건**, 렌트 계약 행 자체가 없음 |
| 예약 | **REJECTED 2건 / CANCELED 2건**, 미완료 예약·미인수 회수 0건 |
| 연결 결제 | 기존 Sandbox 결제 REFUNDED / 환불 COMPLETED, 남은 환불 0건 |
| 계정/지점 | 활성 상태 유지 |
| 이번 종료 처리 | 대상이 없어 **변경 0건**. 예약·결제·차량·이력 삭제/강제 취소 없음 |

**렌트가 남아 삭제 시험이 막힌 상태는 아니다.** 해당 대표가 이미 접수한 SUBTREE 개인정보 요청이 **ACTION_REQUIRED / CONTACT_OPERATOR**, attempts=5로 멈춰 있다. 접수 안내 완료 기록은 0건이며 권한 회수·개인정보 정리 단계는 시작되지 않았다. 등록 이메일 누락은 없지만 실패 원문/공급자 결과를 확인하지 않았으므로 SMTP 인증 문제라고 단정하지 않는다.

요청 문서에 남은 당시 pendingReservations=2는 저장된 과거 집계다. 현재 SQL의 예약은 모두 취소/거절됐고 렌트도 없어 **현재 미완료 수는 0건**이다. 기존 요청 상태/지점 차단 표시를 지우거나 새 요청으로 우회하지 않았다.

삭제 시험을 이어가려면 운영자가 같은 요청의 접수 안내/체크포인트 실패 원인을 확인하고 복구해야 한다. **resume은 실제 권한 회수·익명화·Auth 삭제로 진행될 수 있어 이번 “실제 계정 탈퇴 시험 금지” 범위에서는 실행하지 않았다.** 계정이 즉시 새 삭제 시험을 할 수 있는 상태라고 표시하지 않는다.
